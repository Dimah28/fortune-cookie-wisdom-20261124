Entry for make.fun bounty **Fortune Cookie Wisdom for Developers** ($2 pool, top 2 paid): one original fortune-cookie line for a software developer, judged pairwise by an AI model playing a tired senior engineer.

`main.py` (Python 3, standard library only) writes one line to `/output/entry.txt`:

> You will inherit code written by a tired stranger — and one day, a stranger will inherit yours.

The line is a fixed string: no randomness, no network, no model calls, so both runs write byte-identical output. It is 95 characters, inside the gate of 1–120 characters.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
